GamePilot Privacy Policy

Last Updated: March 8, 2026

1. Data Collection

GamePilot is designed with privacy as a top priority. We collect minimal data necessary for the application to function:

  • Local Game Library Data: Game titles, installation paths, and basic metadata stored locally on your device
  • Application Settings: User preferences, theme selections, and customization options
  • Achievement Data: Local achievement progress and gaming statistics
Important: All data is stored locally on your device. GamePilot does not transmit any personal data to external servers.

2. No Data Transmission

GamePilot operates entirely offline:

  • No data is sent to our servers
  • No analytics or tracking
  • No telemetry collection
  • No third-party data sharing

3. Game Detection Process

GamePilot only reads publicly available metadata:

  • Scans local game installation directories
  • Reads executable files and manifest data
  • Does not modify or copy game files
  • Does not access game save data

4. Third-Party Services

GamePilot may integrate with external services only when explicitly activated by you:

  • Steam API: Only when you manually connect your Steam account
  • Epic Games Store: Only when you manually connect your Epic account
  • GOG Galaxy: Only when you manually connect your GOG account

These integrations are optional and require your explicit consent.

5. Data Storage

All your data is stored locally:

  • Windows: %APPDATA%/GamePilot/
  • Settings and preferences in JSON format
  • Achievement data in local database
  • Theme and customization files

6. Your Rights

You have complete control over your data:

  • Access: View all stored data in the application settings
  • Export: Export your settings and data at any time
  • Delete: Remove all data with the "Reset All" option
  • Opt-out: Disable any optional integrations

7. Security

We protect your data with:

  • Local encryption for sensitive settings
  • Secure file permissions
  • No network transmission of personal data
  • Regular security updates

8. Children's Privacy

GamePilot does not collect personal information from children under 13. Since all data is stored locally, parents have full control and visibility over any data stored by the application.

9. Changes to This Policy

We may update this privacy policy occasionally. The "Last Updated" date at the top of this page will reflect any changes. Significant changes will be highlighted in the application.
