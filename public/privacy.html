GamePilot Privacy Policy

Last Updated: November 18, 2026

1. Local Data

GamePilot stores the information it uses on your device, including:

  • Game library data: Game titles, installation paths, launch settings, and metadata
  • Gaming history: Session times, playtime, optional journal notes, achievements, and biography data
  • Application settings: Preferences, themes, customization options, and optional account identifiers
Local-first: Your library, sessions, and biography are stored locally. No GamePilot account is required. Optional online features make the limited external requests described below.

2. Network Access and Telemetry

Core session tracking, recommendations, and biography generation work without a GamePilot account or analytics service. GamePilot does not collect analytics or advertising telemetry.

The application is not entirely offline. Optional integrations, metadata lookups, price checks, update checks, and some Steam features contact external services. The information sent depends on the feature and is described in Section 4.

3. Local Scanning and Game Files

Ordinary library scanning reads local installation directories, executable and manifest metadata, and running-process information needed for session tracking. It does not modify game files.

Separate features can access local screenshots, emulator files, and save data when you use them. Save backup or restore, uninstall planning, and storage cleaning only perform file changes after you choose those actions.

4. Third-Party Services

When you use online features, GamePilot sends the information needed for that request to the relevant provider. Examples include:

  • Steam and the GamePilot Netlify relay: Your Steam64 ID and, for achievements, an app ID. Some profile, friends, owned-library, and achievement requests use the relay so the Steam API key stays out of the application.
  • CheapShark: Wishlist game titles for price searches and deal lookups when price checking is enabled and your wishlist has entries.
  • Metadata and artwork providers: Game titles or public app IDs sent to services such as IGDB, SteamGridDB, HowLongToBeat, and PCGamingWiki when those lookups are used.
  • Optional account integrations: Credentials or identifiers supplied to Epic, itch.io, RetroAchievements, YouTube, or Discord for the feature you enable.

These providers have their own privacy policies and server logs. GamePilot does not sell your data or build an advertising profile from it.

5. Data Storage and Credentials

GamePilot stores data in its local application data directory, including JSON/localStorage values, SQLite session databases, and rolling session-history backups.

  • Windows: %APPDATA%/GamePilot/
  • Linux: ~/.config/GamePilot/
  • Epic and YouTube tokens use Electron safeStorage encryption where available. Other optional API keys are stored locally without application-level encryption.
  • Known API credentials are excluded from JSON backup exports, but exports can contain personal gaming history and journal notes. Keep them private.

6. Your Choices

  • Access and export: View and export your local data through the available settings and backup tools.
  • Delete: The full data-clearing action removes GamePilot settings, library and session history, including rolling session-history backups. You can delete the entire GamePilot data folder to remove remaining application-created files.
  • Opt out: Disable optional integrations and data sources where settings are provided.

Files you explicitly created outside the GamePilot data folder, such as exported backups or save backups, are not deleted.

7. Security

GamePilot uses an isolated, sandboxed renderer, restricted IPC handlers, transactional session writes, and safeguards against accidental history loss. These protections do not guarantee absolute security.

Local data is protected primarily by your operating-system account and device security. Data stored without application-level encryption may be readable by other software or people with access to that account.

8. Children's Privacy

GamePilot has no account system and does not knowingly collect personal information from children under 13. Parents and guardians should review the optional online integrations and the privacy policies of any third-party services used.

9. Changes to This Policy

We may update this privacy policy occasionally. The "Last Updated" date at the top of this page will reflect any changes. Significant changes will be highlighted in the application.
